### A super simple, single-page notepad with frequently used hotkeys (keyboard shortcuts).


---
- **Bold Text** — `Ctrl` / `⌘` + **B**
- **Highlight Text** — `Ctrl` / `⌘` + **H**
- **Increase Font Size** — `Ctrl` / `⌘` + **+**
- **Decrease Font Size** — `Ctrl` / `⌘` + **-**
- **Reset Font Size** — `Ctrl` / `⌘` + **0**
